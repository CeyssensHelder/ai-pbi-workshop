# Visual guidelines

## Page layout (16:9, 1280 x 720)
1. **Top row:** title (left) and slicers (right).
2. **KPI row:** 3–5 cards with the headline measures, each with its comparison (e.g. "vs PY +4.2%").
3. **Main visual:** the chart that answers the core question. It gets the most space.
4. **Supporting visuals:** 1–2 breakdowns or a detail table.
5. **Footer:** a "Definitions" text box (measures used, period, data cut-off).

## Choosing a chart
| Question | Visual |
|---|---|
| How does it change over time? | Line chart (months on the x-axis). Columns if fewer than 12 points |
| How do segments compare? | Horizontal bar chart, sorted descending |
| What's the mix or share? | 100% stacked bar. Pie/donut only for 2–4 slices |
| Where is it? | Bar by country. A map only if the location really matters |
| Which items, exactly? | Table or matrix with conditional formatting, Top N |
| Relationship between two measures | Scatter chart |

## Rules
- At most ~6 visuals per page, one question per page.
- Sort bars by value, not alphabetically (except for time).
- Use the measure formats from the glossary ($ and %). Don't show more than one decimal on percentages.
- Use the theme colours. Highlight one series and keep the rest neutral. Avoid red/green as the only distinction.
- Titles state the takeaway or the question ("Net Sales by Category, 2023"), not just the field name.
- Label 2024 as "YTD" wherever it appears.
