# Request checklist

Fill these in from the user's request. Ask only about what's missing, and offer sensible defaults.

| Item | Question to answer | Default if the user has no preference |
|---|---|---|
| Audience | Who reads it, and what decision do they make with it? | The requester's team |
| Core question | What single question does the page answer? | Must come from the user |
| KPIs | Which measures? (glossary names) | Net Sales, Gross Margin %, Orders |
| Period | Which time range? | Last full year (2023), with the previous year as comparison |
| Comparison | vs previous year, vs target, vs other segments? | vs previous year |
| Breakdown | By what? (category, country, store, month) | Month for trends, category for mix |
| Detail level | Top-N, or everything? | Top 10 |
| Filters | Which slicers should the reader control? | Year, Category, Store Country |
| Currency | USD, or local currency? | USD (local only when filtered to one currency) |
| Partial year | Include 2024 (data until 20 April)? | Exclude, or label it "2024 YTD" |
